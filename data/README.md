# Local data

Raw scans, manifests with patient identifiers, and split files stay local and are ignored by Git.
Use `data/raw/isles-2022/` for an authorized extracted release. Paths in the study-index CSV
are relative to that dataset root. The example CSV is a schema example, not an ISLES filename template.
Consult `docs/DATASET_SETUP.md` before indexing real scans.
