# Public source repository

This repository distributes NeuroFusion's research software, tests and documentation.
It does not include datasets, patient uploads, review accounts, private results,
trained checkpoints or the local Python environment. References to local experiment
artifacts describe evidence on the original development machine; those artifacts
are not available from this repository.

The existing local installation can run with its existing checkpoints. A fresh
clone alone cannot run model inference: it needs compatible dependencies and
authorized model artifacts. No medical performance or independent qualification
is implied by the research-delivery completion status.

GitHub publication is source hosting only. The Python inference server has not
been deployed publicly. Run it on loopback according to the local viewer guide.
